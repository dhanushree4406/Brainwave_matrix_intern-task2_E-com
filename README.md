# 👟 Sneaker E-Commerce Website

A responsive **Sneaker E-Commerce Website** developed using **HTML, CSS and JavaScript**, designed to provide users with an interactive online shopping experience to explore sneaker collections, view product details and proceed through a checkout interface.

## 🖥️ Project Overview

This project is an interactive online sneaker shopping website featuring different sneaker collections such as Air Force, Air Jordan, Blazer, Crater and Hippie. It includes product navigation, image sliders, product selection options and a checkout interface.

**Developed as part of my Web Development Internship at Brainwave Matrix Solutions.**

## 🛠️ Technologies Used

- **HTML5** – Structure and content of the website.
- **CSS3** – Styling, layouts and responsive user interface.
- **JavaScript** – Interactive elements, product navigation and shopping functionality.

## ✨ Key Features

- 👟 **Multiple Sneaker Collections** – Air Force, Air Jordan, Blazer, Crater and Hippie.
- 🔄 **Interactive Product Slider** – Navigate between different sneaker collections.
- 🔍 **Search Interface** – Search bar for product navigation.
- 💰 **Product Details** – Displays product names and prices.
- 🎨 **Colour Selection** – Choose available product colours.
- 📏 **Size Selection** – Select different shoe sizes.
- 🛒 **Buy Now Option** – Opens the product purchase interface.
- 💳 **Checkout Interface** – Includes personal and card information fields.
- 🚚 **Shopping Benefits Section** – Displays shipping, returns, gift cards and contact information.
- 📱 **Promotional Sections** – Showcases seasonal collections and offers.

## ⚙️ How It Works

1. **Explore Products:** Browse through different sneaker collections using the navigation menu and product slider.
2. **Select a Product:** Choose a sneaker collection to view its product details.
3. **View Product Information:** Check the product name and price.
4. **Choose Preferences:** Select the available colour and shoe size.
5. **Buy Now:** Open the checkout interface.
6. **Enter Details:** Fill in the personal and payment information fields.
7. **Explore More:** Navigate through promotional sections, shopping benefits and other website features.

## 🚀 How to Run the Project

**Prerequisites:**

- Visual Studio Code
- Any modern web browser
- Live Server Extension (Recommended)

**Steps:**

1. Clone the repository:

   ```bash
   git clone https://github.com/dhanushree4406/Brainwave_matrix_intern-task2_E-com.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Brainwave_matrix_intern-task2_E-com
   ```

3. Open the project folder in **Visual Studio Code**.

4. Open `index.html` using **Live Server** or directly in your browser.

5. Explore the sneaker collections and interact with the shopping interface!
